오늘의 용어

JSON이름표 · 번호가 붙은 서랍장 모양의 데이터 글
객체 { }이름표(키)로 여는 서랍 — "name": "성산일출봉"
배열 [ ]번호로 여는 서랍 — 0부터 센다
키 · 값이름표와 그 안에 든 것
주소(경로)서랍을 여는 순서 — data.spots[0].name
점 .이름표 서랍 하나 열기
인덱스 [0]번호 서랍 열기 — 첫 번째가 0
length배열의 칸 수 — 마지막 번호는 length − 1
for … of서랍을 하나씩 집어(s) 같은 일 반복
if조건이 맞는 서랍만 통과시키는 체
=== · &&같다 · 그리고
includes글자가 들어 있는지
이벤트“누르면 그때 해 줘” — 버튼에 할 일 맡기기
addEventListener진짜 코드에서 버튼에 할 일을 잇는 말
undefined“그런 서랍 없어요” — 철자부터 확인
Object.keys이름표 목록 꺼내기
API 응답남이 돌려준 JSON — 똑같이 꺼낸다
