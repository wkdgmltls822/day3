서랍장(JSON)에서 원하는 것을 꺼낸다 — 점 · 번호 · 반복 · 조건 · 이벤트

교육 목표어제 배운 객체 · 반복문 · 이벤트를 JSON 데이터에 그대로 써 본다. jeju_spots.json 과 날씨 응답 JSON 에서 ‘주소’로 값을 꺼내고, 반복문으로 전부 · 조건으로 골라 꺼내고, 버튼을 누르면 꺼내 보여 주는 페이지를 만든다. 마지막엔 내 JSON 을 직접 만들어 꺼낸다.당일 결과물연습장 52 미션 ✓ · spots_list.html(목록 · 세기 · 버튼) · 개인 과제 제출 파일(json_hw_번호.txt)도전 과제연습장에서 못 푼 미션을 모두 ✓ 로 채우고, 8교시 ‘도전 과제’ 프롬프트로 my_data.json + my_page.html(내 JSON 버튼 페이지)을 만들어 가족 · 친구 1명에게 “이 글자는 data.___ 에서 꺼낸 거야” 하고 주소 하나를 설명해 보기. 설명한 주소를 한 줄 적어 오기.사용 도구과제_JSON꺼내기_학생용.html · 과제_JSON꺼내기_채점기_강사용.html(8교시) · Claude 데스크톱 앱(Code 탭 · Plan / Manual) · Browser 패널(미리보기) · JSON꺼내기_연습장.html(브라우저에서 열기, 인터넷 없어도 됨) · jeju_spots.json v2 · (선택) Open-Meteo 예보(키 없음)사다리객체 · 반복문 · 이벤트(어제) → ★JSON 꺼내기(오늘) → 4일차 AI 추천 · 5일차 에이전트가 이 서랍장에서 꺼내 씁니다진행 원칙코드는 연습장의 한두 줄만 손으로 친다. 페이지는 Claude 가 만들고, 학생은 ‘꺼내는 줄’을 찾아 읽는다. 매 교시 = 개념 10분 → 연습장 20분 → Claude 실습 15분 → 정리 5분.

JSON 은 서랍장 — 객체 { } · 배열 [ ] 다시 보기

09:00–09:50
🎯 어제 배운 객체 · 배열이 JSON 파일 안에서 어떻게 생겼는지 ‘서랍장’으로 보고, 연습장에서 값을 눌러 그 자리의 주소를 읽는다.

진행 순서 (50분)

10분어제 배운 것 한 줄씩 — 객체 = 이름표 서랍 · 배열 = 번호 서랍 · 반복 = 하나씩 · 이벤트 = 누르면
10분jeju_spots.json 을 메모장(또는 Code 탭)으로 열기 — { 와 [ 를 찾아 손가락으로 짚기
5분연습장 여는 법 — 파일 더블클릭 · ⭐ 개수 · 단계 탭
20분★ 실습: 연습장 1단계 6문제 — 값을 누르면 주소가 나온다 · 짝꿍에게 주소 소리 내어 읽어 주기
5분정리 — 주소 = 서랍을 여는 순서 (바깥 → 안쪽)

핵심 멘트

  • “JSON 은 어려운 게 아니에요. 이름표가 붙은 서랍장이에요.”
  • “오늘 하루는 딱 하나만 익힙니다. 서랍장에서 원하는 걸 꺼내는 ‘주소’ 쓰기.”
  • “4일차 추천, 5일차 에이전트도 전부 이 서랍장에서 꺼내 씁니다. 오늘이 그 기초 공사예요.”

판서

[ ] 번호 서랍 → 0부터 data.spots[0] 마지막 = [length − 1]
전부 for (const s of data.spots) { show(s.name) }
골라 if (s.area === '동쪽') ===같다 &&그리고 >=이상 .includes('글자')

오늘의 용어

JSON이름표 · 번호가 붙은 서랍장 모양의 데이터 글
객체 { }이름표(키)로 여는 서랍 — "name": "성산일출봉"
배열 [ ]번호로 여는 서랍 — 0부터 센다
키 · 값이름표와 그 안에 든 것
주소(경로)서랍을 여는 순서 — data.spots[0].name
점 .이름표 서랍 하나 열기
인덱스 [0]번호 서랍 열기 — 첫 번째가 0
length배열의 칸 수 — 마지막 번호는 length − 1
for … of서랍을 하나씩 집어(s) 같은 일 반복
if조건이 맞는 서랍만 통과시키는 체
=== · &&같다 · 그리고
includes글자가 들어 있는지
이벤트“누르면 그때 해 줘” — 버튼에 할 일 맡기기
addEventListener진짜 코드에서 버튼에 할 일을 잇는 말
undefined“그런 서랍 없어요” — 철자부터 확인
Object.keys이름표 목록 꺼내기
API 응답남이 돌려준 JSON — 똑같이 꺼낸다
